About Me

I’m a final-year Computer Science and System Engineering student at KIIT University, graduating in 2027, with a focus on AI/ML engineering and an expanding foundation in cybersecurity.

My work in AI spans machine learning, deep learning, NLP and generative AI. I enjoy building end-to-end applications, from model development and LLM-based workflows to backend APIs, database integration and deployment.

My flagship project, NutriAI, reflects this approach: a multi-agent nutrition assistant built with LangGraph and FastAPI, combining LLM reasoning, database retrieval and persistent memory. You can explore the implementation and other projects on the Projects page.

Alongside AI, I’ve developed a strong interest in network and infrastructure security. During my Infrastructure Security internship at HCLTech, I explored enterprise networking and security through hands-on labs involving Cisco ASA firewalls, access control, NAT/PAT, Site-to-Site IPsec VPNs and threat analysis. I’ve also gained exposure to Palo Alto firewall environments and core security concepts.

What interests me most is the intersection of these two fields: how AI can introduce new security challenges, how it can strengthen threat detection, and how the infrastructure behind intelligent systems can be secured.

I want to build systems that are not only useful and scalable, but also designed with security in mind.

MAJOR PROJECT · AI ENGINEERING

NutriAI — Multi-Agent LLM Nutrition Assistant

A multi-agent nutrition assistant that answers food and meal questions while keeping latency low and flagging uncertain estimates.

  • Three specialized LangGraph agents with sequential, parallel and human-in-the-loop workflows
  • Five-layer pipeline (cache → DB → fuzzy match → dual-LLM → fallback) cutting repeat-query latency by ~99%
  • Dual-LLM ensemble (Qwen + Llama) with divergence detection to reduce hallucination risk
  • FastAPI backend with 25+ REST endpoints, OCR menu ingestion and ChromaDB RAG over 500+ dishes
  • Docker multi-stage builds, deployed on Docker Hub and Render
